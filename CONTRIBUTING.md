# Contributing

Contributions are welcome through focused pull requests.

## Expectations

1. Keep each skill independently installable under `skills/<skill-name>`.
2. Preserve concise, discriminating `SKILL.md` frontmatter.
3. Add or update tests before changing executable behavior.
4. Run the checks in [docs/testing.md](docs/testing.md).
5. Cite primary scientific or official technical sources where applicable.
6. Do not add credentials, personal activity files, copyrighted papers, caches, or machine-specific paths.

Scientific records must state their review status and provenance. Do not convert an abstract-only record into a full-text finding. Garmin API changes should be checked against the official Connect IQ documentation.

By contributing self-authored material, you agree that it may be distributed under the repository's MIT License. Do not submit third-party material unless redistribution is permitted and attribution is preserved.
