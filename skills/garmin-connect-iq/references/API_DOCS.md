# Garmin API documentation

Garmin's Connect IQ API documentation is not redistributed in this repository.

Use the [official online API documentation](https://developer.garmin.com/connect-iq/api-docs/), or run `powershell -File scripts/sync-api-docs.ps1` from the skill directory to create a private local mirror for development use. Review Garmin's current Connect IQ Developer Agreement before downloading Program Materials, and do not commit or redistribute the generated `api-docs/` directory.
